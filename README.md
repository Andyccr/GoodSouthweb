# GOOD SOUTH — 南境据点

网页版 **岛屿塔防沙盒**，玩法模仿 [Bad North](https://en.wikipedia.org/wiki/Bad_North)：随机群岛、海滩登陆、布置兵团、保护屋舍。画面用 **矮人要塞（Dwarf Fortress）式 ASCII / 16 色字符**，不依赖图片资源。

打开 [`index.html`](index.html)（本地建议用静态服务器）：

```bash
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

或 `npm start`。

## 两种模式

### 战役

程序化生成一整条南境岛链。从西侧家园出发，沿航线推进：

1. 在海图上选择已侦察的岛
2. **布置阶段**把盾兵 / 弓手 / 枪兵放到陆地上，用右键或 `R` 旋转朝向
3. 按 `G` 开战；北蛮长船从海滩方向靠岸
4. 守住屋舍直到所有波次结束 → 按残存屋舍获得钱币
5. 用钱币招募新队长；兵团在战斗中减员，队长死则该编制消失

### 沙盒

指定 **种子 / 生态 / 威胁** 即时刷岛，用地形笔刷改地块，随时刷北蛮、长船或己方兵。适合研究地形与阵型，不走战役经济。

生态：沃野、岩礁、泽地、霜岛、火山。

## 兵种（Bad North 对应）

| 字符 | 兵种 | 职责 |
|------|------|------|
| ☻ `@` | 盾兵 | 近战抗打，卡海滩与路口 |
| `}` | 弓手 | 远程；高地射程与伤害加成，树木/石墙挡视线 |
| `↑` | 枪兵 | **正面**对冲锋高伤，侧后较弱 |
| `v` `V` `x` `Ω` | 北蛮 | 掠袭者、蛮力士、投斧手、领主 |

敌人会寻路扑向最近的屋舍；屋舍耐久耗尽即焚毁。

## 地图生成

每座岛用种子噪声 + 岛形蒙版生成：

- 不规则岸线、双丘地峡、内湖、斜坡
- 海滩登陆点按「朝向开阔海域的方向」检测
- 房屋放在内陆，并保证从至少一个登陆点可以走到
- 失败会自动重试；最坏情况回退到保底岛

同一数字/字符串种子会得到同一张岛。

## 地图与玩法要点

- 岛屿约 **80–108 × 60–84**（威胁越高越大），外圈是深海；沙盒可选 小/中/大（大图可达约 120×90）
- 战斗用**镜头**：滚轮缩放、中键拖拽平移，不再把整座岛压进一屏
- 北蛮**乘长船从海平线驶来**，贴岸后才下船
- 海图约 14 岛；高威胁波次可能**双向登陆**
- **烽火台 ¥**：附近弓手射程与伤害提升
- **乡勇**：屋舍首次遇袭时冲出村民拖延
- **号角 U**：每场战斗一次，短时大幅减速北蛮

## 保存与暂停

- **Esc**：打开暂停菜单（战役 / 战斗 / 沙盒）
- **空格**：战斗内软暂停（只冻时间）
- **F5**：快速写入自动档（战斗中会带战局快照）
- **F9**：读取最近存档
- 暂停菜单可写入 **自动 / 1 / 2 / 3** 四个槽位
- 调色与静音写入本地设置，刷新后保留
- 切换浏览器标签会自动暂停战斗

## 架构

详见 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)。分层摘要：

- **Core**：`events` 总线 · `config` 数值 · `rng` / `util`
- **Domain**：`army` · `campaign` · `save` · `waves`
- **Simulation**：`sim`（Battle）· `mapgen` · `pathfind`
- **Presentation**：`render` · `ui` · `screens` · `hud` · `audio`
- **Application**：`game`（模式状态机 + `dispatch`）· `input` · `app`（boot）

所有键盘/鼠标/按钮最终进入 `Game.dispatch(act, arg)`，避免 UI 与模拟互相缠绕。
